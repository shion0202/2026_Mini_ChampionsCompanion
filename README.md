# 챔피언스 컴패니언

안드로이드에서 포켓몬 챔피언스 통계를 빠르게 조회하는 비공식 개인용 웹앱입니다. PC에서도 사용할 수 있습니다. 첫 버전은 통계 기능에 집중합니다.

## 실행

Node.js 22 이상이 필요합니다. 라이브러리 설치 없이 프로젝트 폴더에서 실행합니다.

```powershell
node scripts/serve.mjs
```

브라우저에서 <http://localhost:4173>을 엽니다. 종료는 실행 터미널에서 Ctrl+C입니다.

같은 Wi-Fi에 있는 안드로이드 휴대폰으로 확인하려면:

```powershell
node scripts/serve.mjs --host --port 4174
```

출력되는 `LAN preview` 주소를 휴대폰 Chrome에서 엽니다. PC가 켜져 있어야 하며 방화벽 설정에 따라 연결되지 않을 수 있습니다. 앱은 방화벽 설정을 변경하지 않습니다. LAN HTTP 주소는 화면 조회용이고, 설치·오프라인 기능은 HTTPS 또는 localhost가 필요합니다.

## 현재 기능

- 싱글/더블, 제공처가 공개한 시즌별 포켓몬 랭킹
- 기술·도구·같은 팀·능력 보정·능력 포인트·특성 통계
- 한국어 이름·초성·영문·도감 번호 검색 및 즐겨찾기
- 자료 날짜, API 생성 시각, 기기 조회 시각을 구분한 표시
- 1시간 조회 캐시, 실패 시 같은 시즌·배틀 형식의 최근 정상 자료 사용과 이전 날짜·시각 안내
- 자료 형식을 확인할 수 없는 포켓몬은 목록에서 제외하고 제외한 수를 안내. 읽을 수 있는 항목이 하나도 없으면 조회 실패로 처리
- 모바일 상세 화면 및 PC 목록/상세 병렬 화면
- PWA 설치 정보와 정적 앱 파일 오프라인 지원
- 시스템/라이트/다크 테마, 선택 저장
- 이름순·도감번호순·사용 순위 및 역순, 세대/타입 필터
- 통계 상세의 ‘기본 정보’: 타입, 키, 몸무게, 특성, 종족값과 실수치, 타입 방어상성, 메가 폼 전환
- 기술·도구·특성 이름을 눌러 한국어 효과 팝업 열기
- 헤더의 ‘도감’에서 기술 951개, 도구 581개, 특성 318개를 포켓몬과 무관하게 검색. 기술은 타입·물리/특수/변화·성질 필터를 함께 사용하며, `#dex=move`처럼 주소로 바로 열 수 있습니다
- 챔피언스 전용 ‘배우는 기술’: 이름·초성 검색, 타입과 물리/특수/변화 필터
- 능력 포인트 ‘합산/원본’: 32포인트 능력치 집합이 같은 상위 배분 합산, 펼쳐서 원본 확인

자료 날짜를 누르면 API 생성 시각을 볼 수 있습니다. 상세 화면 아래의 ‘자료 시각 자세히’에서도 확인할 수 있습니다. API 생성 시각은 인게임 갱신 시각이 아닙니다.

즐겨찾기와 선택한 시즌/형식은 해당 브라우저에 저장됩니다. 통계는 인덱스 포함 최대 5건을 7일 이내로 임시 보관하며, 앱을 열거나 자료를 조회할 때 오래된 항목을 정리합니다. 브라우저 저장 공간 삭제 시 함께 지워집니다. 오프라인에서는 이전에 조회하여 남아 있는 자료만 볼 수 있으며 포켓몬 이미지는 표시되지 않을 수 있습니다.

## 빌드와 검증

```powershell
node --test tests/*.test.mjs
node scripts/build.mjs
node scripts/serve.mjs --dist --port 4174
```

`dist/`에 정적 배포 파일을 생성합니다. HTTPS 정적 호스팅에 올릴 수 있지만 이 작업에서는 외부 공개/배포를 하지 않았습니다. 사용자 데이터 서버는 없습니다.

렌더 결과는 스냅샷으로 비교합니다. 상세 화면의 도감·기술·효과는 `tests/reference-view.test.mjs`가, 랭킹 목록과 상세 화면 틀·필터는 `tests/app-view.test.mjs`가 담당합니다. 마크업을 의도적으로 바꾼 뒤에는 `node --test --test-update-snapshots tests/*.test.mjs`로 갱신하고 함께 저장된 `.snapshot` 파일의 차이를 확인합니다.

`src/app.js`에는 상태 보관과 DOM 조작, 이벤트 연결만 남겼습니다. 마크업 생성은 `src/app-view.js`와 `src/reference-view.js`가, 저장된 설정 읽기·시즌과 형식 확인·목록 구성·안내 문구 같은 판단은 `src/app-state.js`가 맡습니다. 세 모듈 모두 인자만 받아 값을 돌려주므로 브라우저 없이 검증할 수 있고 `tests/app-view.test.mjs`, `tests/app-state.test.mjs`, `tests/reference-view.test.mjs`가 이를 덮습니다. `src/app.js` 자체는 불러올 때 DOM을 사용하므로 `scripts/verify-*-browser.mjs`가 해당 범위를 담당합니다.

코드 서식은 Prettier로 통일합니다. `npm run format`으로 적용하고 `npm run format:check`로 확인합니다. 대상은 `src`, `tests`, `scripts`, `sw.js`이며 `index.html`은 인라인 요소 사이의 공백이 렌더 결과에 영향을 줄 수 있어 제외합니다.

브라우저 검증 스크립트는 선택 사항입니다. Playwright와 Chromium 계열 브라우저가 있으면 개발 서버 실행 후 다음과 같이 사용합니다. 런타임 의존성은 아닙니다.

```powershell
$env:PLAYWRIGHT_MODULE='설치된 playwright의 index.mjs 절대 경로'
$env:BROWSER_EXECUTABLE='브라우저 실행 파일 절대 경로'
node scripts/verify-browser.mjs
```

검증 스크린샷은 Git에 포함하지 않는 `test-results/`에 생성됩니다. 한국어 사전을 갱신하려면 네트워크가 연결된 상태에서 `node scripts/update-locales.mjs`를 실행합니다.

새 기능의 브라우저 검증은 같은 환경 변수로 `node scripts/verify-reference-browser.mjs`를 실행합니다. 도감 데이터 재생성은 Node.js 24 이상에서 `node scripts/update-reference.mjs`로 실행합니다. 원본 리비전은 스크립트 안에 고정되어 있어 반복 실행만으로 새로운 원본으로 바뀌지는 않습니다. 갱신 시 버전 변경과 검증이 필요합니다.

도감 실수치는 챔피언스 Lv.50 기준의 최대/무보정 +32/무보정 +0/최소 범위입니다. 방어상성은 타입 배율과 타입별 특성에 의해 달라지는 배율을 함께 표시합니다. 멀티스케일 같은 전 타입 보정과 접촉 조건, 날씨, 도구, 상대의 특성 무시 및 개별 기술 예외는 제외합니다. 실제 데미지가 아닌 참고 배율입니다. 포인트 합산은 제공된 상위 행만 합치며 전체 분포를 추정하지 않습니다. 세대 필터는 원종의 첫 등장 세대이며, 지역 폼이 추가된 세대와 구분합니다.

## 데이터 및 제한

통계 제공처는 [Pokémon Champions Battle Data](https://championsbattledata.com)입니다. 게임 회사의 공식 공개 API로 확인된 것은 아닙니다. 제공처 웹페이지가 사용하는 공개 JSON 파일에 연결하므로 구조나 CORS 정책이 바뀌면 수정이 필요합니다. 한국어 명칭은 [PokéAPI](https://github.com/PokeAPI/pokeapi) 자료를 사용합니다.

[데이터 계약과 출처](docs/data-source.md), [검증 기록](docs/verification.md), [설계와 후속 범위](docs/design.md)를 참고하세요. 게임 통계 전체의 정확성이나 실시간 일치를 보증하지 않습니다. 실제 안드로이드 기기의 설치/터치 검증은 아직 하지 않았습니다.

계산기, 샘플·파티 저장/불러오기, 엑셀 내보내기와 파티 상성은 후속 구현 범위입니다. 공유 서버, 계정 로그인, 광고, 결제는 없습니다.

포켓몬 관련 명칭·이미지의 권리는 각 권리자에게 있습니다. 이 프로젝트가 제3자 데이터나 이미지의 권리를 부여하는 것은 아닙니다.
