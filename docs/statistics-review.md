# 통계 기능 검토 — 2026-09-20

코드와 브라우저 사용 흐름을 바탕으로 정리한 검토와 후속 적용 현황이다. 사용자 승인에 따라 1번과 3번은 2026-09-20 반영했다. 계산기는 별도 후순위로 유지한다.

## 1. 날짜 변경 시 조회 실패 복구 — 적용 완료

기존에는 인덱스에 새 날짜가 올라왔지만 해당 일별 파일을 받지 못한 경우, 이전 날짜의 정상 자료가 저장돼 있어도 오류 화면으로 전환됐다. 이제 `ApiClient.getSnapshot()`이 같은 시즌·형식의 가장 최근 정상 보관 자료를 선택한다. 현재 실행 중의 정상 자료도 제한적으로 유지하여 저장 공간이 막힌 상황을 지원한다.

이전 자료의 날짜·API 생성·기기 조회 시각은 바뀌지 않고 보관 자료 안내를 표시한다. 다른 시즌·형식·손상·7일 초과·요청 날짜보다 나중인 자료는 제외한다. 날짜 변경 실패·새로 열기·시간 보존·형식 혼동 방지·정상 복귀를 자동 검증했다.

## 2. 대전 중 빠른 탐색 — 우선순위 중간

현재 기본 정보가 첫 화면이고 기술·도구·특성은 각 탭에서 확인한다. 상대 구성을 짧은 시간에 확인하려면 여러 탭을 오가게 된다. 기본 정보 진입은 유지하면서 상위 기술·도구·특성 요약을 접을 수 있게 제공하거나, 최근 확인한 포켓몬으로 바로 이동하는 기능이 유용할 수 있다. 모바일 화면 길이와 정보량을 늘리는 비용도 있어 실제 사용 후 결정하는 편이 좋다.

## 3. 방어상성의 특성 반영 — 적용 완료

기본 정보의 방어상성에서 해당 폼의 특성을 직접 선택한다. 타입만 보기로 언제든 복원할 수 있다. 무효·타입별 증감·약점 감소를 반영하고 HP 가득 참·접촉·공격 분류 조건은 별도로 선택한다. 폼·포켓몬을 변경하면 초기화하며 통계의 최다 특성을 자동 적용하지 않는다. 실제 데미지가 아닌 참고 배율로 표시하고, 날씨·필드·특성 무시·개별 기술 예외 등 미반영 범위를 명시한다. 모든 특성의 전투 효과를 시뮬레이션하는 기능은 아니다.

## 4. 표시 설정과 이미지 — 우선순위 낮음

시즌·싱글/더블·테마·즐겨찾기·포인트 표시 방식은 저장하지만 정렬·타입·세대 필터는 새로 열 때 초기화된다. 정렬은 저장하고 필터는 초기화할지 등 사용 흐름에 맞춘 결정이 필요하다. 외부 이미지가 없는 경우 대체 표시는 있으나 전체 폼·도구의 이미지 가용성을 전수 확인하지는 않았다.
