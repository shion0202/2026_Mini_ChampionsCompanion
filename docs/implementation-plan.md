# 통계 첫 버전 구현 계획 및 결과

설계: [design.md](design.md). 목표: 실제 제공처 데이터로 동작하는 한국어 모바일 우선 통계 앱.

- [x] 프로젝트 폴더와 Git 저장소 생성
- [x] 공개 데이터 계약 확인과 문서화
- [x] 시즌·형식·날짜·폼을 보존하는 어댑터와 데이터 검증 테스트
- [x] PokéAPI 한국어 명칭 사전 생성 및 폼 매핑
- [x] 실패·만료·저장 공간 사용 불가를 처리하는 임시 조회 캐시
- [x] 모바일 랭킹/상세, PC 병렬 화면, 검색과 즐겨찾기
- [x] 6종 통계 탭과 자료 날짜/API 생성/기기 조회 시각
- [x] PWA 설치 정보와 앱 파일 오프라인 캐시
- [x] 실제 API 브라우저 검증, 단위 테스트 22개, 빌드
- [x] 실행 방법·데이터 출처·검증 한계 문서화 및 로컬 미리보기

초기 계획의 개별 /api/battle 호출 대신 제공처 메타 페이지의 공개 /data/meta 일별 파일을 채택했습니다. 이 파일은 해당 시즌 순위와 상세 통계를 같은 날짜로 제공하고 포켓몬 선택 시 추가 통신이 필요 없습니다. normalizeIndex, normalizeSnapshot이 실제 어댑터이며, 경로의 안정성이 보장되지 않는다는 제한은 [data-source.md](data-source.md)에 기록했습니다.

실기기 설치와 HTTPS 공개 배포는 아직 수행하지 않았습니다. 계산기, 샘플/파티 저장 및 엑셀 내보내기는 [design.md](design.md)의 후속 범위로 유지합니다.
