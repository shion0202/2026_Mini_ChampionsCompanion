# 데이터 출처와 계약

확인일: 2026-09-19. 통계 제공: [Pokémon Champions Battle Data](https://championsbattledata.com). [API 가이드](https://championsbattledata.com/api_guide), [이용 규칙](https://championsbattledata.com/api-rules/).

공식 게임 서버 API가 아니라 제3자 제공처입니다. 가이드의 개별 `/api/battle/...` 경로와 별개로 제공처의 메타 페이지에서 사용하는 공개 JSON을 조회합니다. 이 `/data/meta/` 경로는 문서화된 안정성 계약이 확인된 API가 아닙니다. 읽기 공개와 장기 지원 약속은 구분합니다.

## 실제 요청

1. `https://championsbattledata.com/data/meta/index.json`
2. `https://championsbattledata.com/data/meta/{season}/{date}/{format}.json`

예: `/data/meta/M6/19_09_2026/Singles.json`. 날짜를 하드코딩하지 않고 인덱스가 공개한 시즌별 최신 날짜를 선택합니다. `format`은 `Singles` 또는 `Doubles`입니다. 확인 시 CORS를 통해 브라우저 직접 조회가 가능했습니다.

인덱스의 `seasons`는 `season`, `dates`, `formats`를 포함합니다. `pokemon`은 영문 폼 이름별 이름/타입/이미지 경로 메타데이터입니다. 일별 파일 하나에 그 날짜와 형식의 순위 및 모든 포켓몬 상세 통계가 함께 있어, 순위와 상세에 같은 스냅샷을 사용합니다. 포켓몬을 누를 때 추가 통계 요청은 없습니다.

일별 파일 최상위 `season`, `date`, `format`을 요청 조건과 검증합니다. `pokemon` 객체 항목의 `position`이 사용 순위입니다. 사용 순위 자체로 사용률 %를 만들어내지 않습니다.

| 필드 | 원본 행 구조 | 표시 |
|---|---|---|
| move | `[이름, 비율, 순위]` | 기술별 % |
| held_item | `[이름, 비율, 순위]` | 도구별 % |
| teammate | `[포켓몬 이름, 순위]` | 순위만, 비율 없음 |
| stat_alignment | `[이름, 비율, 상승 능력, 하락 능력, 순위]` | 능력 보정과 % |
| stat_points | `[비율, HP, 공격, 방어, 특공, 특방, 스피드, 순위]` | 여섯 포인트와 % |
| ability | `[이름, 비율, 순위]` | 특성별 % |

행은 원본 순위로 정렬합니다. 비율 미제공과 실제 0%는 구분합니다. 없는 카테고리는 ‘자료 없음’이며 상위 항목을 임의로 보충하지 않습니다. 능력 포인트는 정수, 각 0~32, 합계 66 이하인지 검사합니다. 시즌/형식 불일치와 잘못된 구조는 거부하고 정상 캐시가 있으면 안내와 함께 사용합니다. 이상치 때문에 스냅샷 전체를 거부할 수 있다는 제한이 있습니다.

## 시각

- `date`: 제공처의 자료 날짜, `DD_MM_YYYY`. 날짜의 시간대는 제공되지 않아 한국 날짜로 변환하지 않습니다.
- `generatedAt`: 제공처 파일의 생성 시각. 유효한 시각은 KST로 표시하며 없으면 ‘제공되지 않음’입니다.
- `fetchedAt`: 이 기기가 실제 네트워크 응답을 받은 시각. 캐시를 표시한다고 바뀌지 않습니다.
- 인게임 갱신 시각: 미제공. 앱에서 추정하지 않습니다.

## 조회와 보관

출처 링크를 항상 노출합니다. 최근 조회 응답을 localStorage에 최대 5건(인덱스 포함), 최대 7일 보관하고 1시간까지 일반 조회에 재사용합니다. 새로고침은 네트워크 조회를 시도합니다. 초기화/조회 시 정리하므로 앱이 닫힌 동안 자동 삭제되는 구조는 아닙니다. 서비스 워커는 앱 파일만 저장하며 통계와 포켓몬 이미지를 보관하지 않습니다. 원본 통계를 저장소에 넣거나 영구 미러, 통계 일괄 내보내기를 만들지 않습니다.

이용 규칙은 확인 당시 출처 표시와 합리적인 캐시를 요구하고 과도한 요청, 독립적인 데이터 덤프/재배포 등을 제한했습니다. 운영 또는 공개 배포 전에 규칙 변경을 다시 확인해야 합니다.

2026-09-20 보강: 새 날짜 파일의 조회 실패 시 같은 시즌·배틀 형식의 정상 보관 자료 중 자료 날짜가 가장 최근인 것을 사용합니다. 요청 날짜보다 나중인 파일, 구조·문맥 불일치, 손상 또는 7일 만료 자료는 제외합니다. 자료 날짜·API 생성 시각·실제 조회 시각을 그대로 유지하며 ‘보관 자료’와 이전 통계 안내를 표시합니다. 저장 공간이 막힌 경우에도 현재 실행 중 받은 정상 스냅샷을 최대 4건 메모리에 유지합니다. 새로고침 성공 시 새 자료로 복귀합니다. 영구 보관 기능은 아닙니다.

## 한국어와 이미지

한국어 이름은 PokéAPI 저장소의 `data/v2/csv` 아래 species/move/item/ability/nature 이름 파일에서 한국어(3)와 영어(9)를 연결합니다. 생성 스크립트와 결과 사전을 함께 보관합니다. 폼은 별도 명시적 매핑을 사용하고, 모르는 명칭은 영문 원문을 보존합니다. Pokémon artwork는 제공처 이미지를 직접 참조하며 이 저장소에 복제하지 않습니다. 앱 아이콘은 자체 제작한 추상 막대 그래프입니다.

메가 폼 이름은 한국어 종 이름 앞에 ‘메가’를 붙이며 X/Y/Z 구분을 보존합니다. 기본 정보에서 메가 폼을 선택하면 상단 이름·타입·이미지도 바뀌며, 통계 탭에서는 원래 집계 대상의 표시로 돌아옵니다. 메가 이미지는 [Showdown sprites](https://play.pokemonshowdown.com/sprites/), 도구 이미지는 [PokéAPI sprites](https://github.com/PokeAPI/sprites)의 원격 URL을 참조합니다. 전체 이미지의 존재를 보장하지 않으며, 로딩 실패 시 미제공 표시로 대체합니다. 서비스 워커에 이미지를 별도 저장하지 않습니다.

## v0.2 배틀 도감

생성 스크립트: `scripts/update-reference.mjs`. 통계 제공처의 집계와 별개인 정적 배틀 참고 데이터입니다. 과거 시즌 통계에도 현재 수록 버전의 도감 정보를 표시하고, 과거 시즌의 출전 허용 정보로 사용하지 않습니다.

- [Pokémon Showdown](https://github.com/smogon/pokemon-showdown/tree/2ddfa0476f8207e12e204b1c69f7c7683b17633c/data): 종족값, 타입, 키·몸무게, 특성, 메가 폼, 타입 상성표. 기술과 아이템은 `mods/champions` 변경을 반영합니다.
- [Champions scripts](https://github.com/smogon/pokemon-showdown/blob/2ddfa0476f8207e12e204b1c69f7c7683b17633c/data/mods/champions/scripts.ts): Lv.50 능력 포인트 실수치 계산. HP=종족값+포인트+75, 나머지=내림((종족값+포인트+20)×능력 보정). 최대는 +32/상승, 최소는 +0/하락. 각 수치의 개별 범위입니다.
- [Project Pokémon champout](https://github.com/projectpokemon/champout/tree/50e7233b78c3b81df29563f9695386c28e77fc95): `rom-txt/kor`/`usa` 명칭을 연결하여 기술·특성·도구의 한국어 효과를 사용합니다. `masterdata/waza.json`의 PP와 실제 이용 가능한 기술 플래그를 반영합니다.
- 기술 목록은 Showdown `mods/champions/learnsets.ts`를 우선합니다. 목록이 없는 크기/색상 폼은 champout의 전국번호, 여섯 종족값, 몸무게가 일치하는 personal 행에 대응시킵니다. 대응하는 모든 행의 사용 가능 기술 목록이 동일한 경우에만 연결하고 출처를 명시합니다. 일반 세대의 기술 목록을 대체재로 사용하지 않습니다.
- 메가 연결은 Showdown의 `baseSpecies` 관계를 사용하되, `battleOnly`가 명시된 경우 그 관계를 우선합니다. 예: 메가플라엣테는 일반 플라엣테가 아니라 영원의 꽃 폼에 연결됩니다.
- 없는 설명은 미제공으로 표시합니다. 원본이 명시적으로 추가 효과 없음(`WAZAINFO_SYN_null`)으로 지정한 기술은 그 사실을 표시합니다. 게임 텍스트의 설명이 모든 세부 상호작용을 설명한다는 뜻은 아닙니다.

출처 리비전과 생성 시각을 데이터에 저장합니다. Showdown MIT 고지는 `public/data/showdown-license.txt`에 보관하며 앱 안내에서 연결합니다. 한국어 게임 텍스트 및 포켓몬 자산의 권리는 원권리자에게 있습니다.

## 선택 특성의 방어 보정

`src/reference.js`의 효과는 도감과 동일한 [Showdown abilities 리비전](https://github.com/smogon/pokemon-showdown/blob/2ddfa0476f8207e12e204b1c69f7c7683b17633c/data/abilities.ts)과 [Champions 변경](https://github.com/smogon/pokemon-showdown/blob/2ddfa0476f8207e12e204b1c69f7c7683b17633c/data/mods/champions/abilities.ts)을 확인해 반영했습니다. 기본은 타입만 보기이며 최다 채용 특성을 자동 적용하지 않습니다. 폼·포켓몬 변경 시 선택을 초기화하고 현재 폼의 특성만 선택할 수 있습니다.

- 타입 무효: 부유·천정부지·흙먹기, 저수·마중물·건조피부, 축전·피뢰침·전기엔진, 타오르는불꽃·노릇노릇바디, 초식.
- 타입별 보정: 두꺼운지방, 내열, 수포, 정화의소금, 건조피부의 불꽃 증가. 필터·하드록·프리즘아머는 원래 약점인 경우만 감소.
- 조건 선택: 멀티스케일·스펙터가드의 HP 가득 참, 복슬복슬·파동의방호의 접촉, 퍼코트·얼음인분의 공격 분류. 불가사의부적의 일반 타입별 무효도 처리.
- 배율은 타입 배율에 특성의 보정을 곱한 참고값입니다. 퍼코트처럼 능력치를 변경하는 효과와 데미지의 정수 반올림을 계산하는 기능은 아닙니다. 날씨·필드·능력치 변화·상대 특성 무시·기술별 예외와 모든 효과 상호작용은 다루지 않습니다. 현재 표에 추가 반영하지 않는 특성을 선택하면 미반영 안내가 나옵니다.
