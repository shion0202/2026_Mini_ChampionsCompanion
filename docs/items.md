# 도구 목록 정리

`src/item-exclusions.js`의 109개는 배틀에서 쓸 수 없어 앞으로도 챔피언스에 들어오지
않을 도구다. 도감을 불러올 때(`pruneItems`) 빼므로 도감의 도구 목록과 선택 창에
나오지 않는다. 수록된 166개는 모두 배틀 효과가 있어 그대로 둔다.

| 묶음 | 수 | 까닭 |
| --- | --- | --- |
| Z 크리스탈 | 35 | Z기술이 없다 |
| 주얼 | 17 | 5세대 뒤로 노말주얼 말고는 다시 나온 적이 없다(노말주얼은 수록) |
| 진화 도구 | 35 | 효과 설명이 ‘진화시킨다 / 좋아하는 물건’뿐이다 |
| 화석·비밀의호박 | 15 | 복원용 |
| 육성·판매용 | 7 | 큰금구슬, 병뚜껑, 고운깃털, 귀중한뼈, 가라두구팔찌·머리장식 |

남기는 것: 특정 포켓몬 전용 도구(메모리, 카세트, 금강옥 등, 가면, 심해의이빨·비늘,
스피드파우더), 플레이트, 모든 메가스톤(전설·환상 포함, 이름이 Z로 끝나는 것 포함),
효과가 있는 진화 관련 도구(진화의휘석, 예리한손톱, 예리한이빨).

이름 규칙으로 거르지 않고 목록으로 고정했다. 앱솔나이트Z처럼 Z로 끝나는 메가스톤이
있어 규칙으로 거르면 잘못 빠진다. `tests/item-exclusions.test.mjs`가 목록의 도구가
모두 도감에 있고, 수록 도구도 메가스톤도 아닌지 검사한다.
