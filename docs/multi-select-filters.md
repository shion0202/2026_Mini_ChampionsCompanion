# 항목별 다중 선택 필터 (2026-09-20)

사용자가 항목별 AND/OR를 선택했다. 랭킹 세대/타입/기믹과 배우는 기술 타입/분류/기술 성질은 여러 값을 선택할 수 있다. 각 항목의 기본 결합은 OR(하나라도), AND(모두)로 변경 가능하다. 항목 사이 및 이름 검색/즐겨찾기 조건은 AND다.

선택하지 않은 항목은 결합 모드와 무관하게 제한이 없다. 기존 ‘기믹 전체’를 ‘제한 없음’으로 교체했다. 기믹 없음은 실제 도감 정보가 있고 현재 폼에 메가 연결이 없는 경우다. 도감 정보 누락을 기믹 없음으로 추정하지 않는다.

세대 1 OR 4, 노말 AND 고스트, 접촉 AND 반동 등의 조합을 지원한다. 세대 1 AND 4처럼 동시에 성립할 수 없는 조합은 정상적으로 빈 결과를 표시한다. 자동으로 OR로 바꾸지 않는다.

필터 창에서는 항목을 펼쳐 체크박스로 고른다. 요약에는 그리고/또는을 사용한다. 전체 초기화는 선택과 결합 모드를 초기화하고, 항목별 선택 해제는 해당 항목만 비운다. 적용 전까지 현재 목록에 영향을 주지 않으며 취소/Escape는 초안을 버린다. 이름과 기믹 필터 등 기존 조건과 함께 동작한다.

작은 화면에서 목록 부분만 스크롤되고 제목과 적용/초기화 버튼은 유지된다. 네이티브 details, checkbox, radio를 사용해 키보드와 화면 읽기를 지원한다.

검증: Node 테스트 52개 통과. 브라우저에서 세대 OR/AND, 이중 타입 AND, 기술 타입/분류 OR와 성질 AND, 조건 변경 취소, 초기화, 제한 없음, 360px/390px/PC 레이아웃을 확인했다. 실제 API 통계/오프라인 및 장애 복구 검사도 통과했다.
