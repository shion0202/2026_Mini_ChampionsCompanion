# Champions Companion — 첫 버전 설계

사용자가 이 대화에서 합의한 요구사항을 기준으로 2026-09-19 작성.

## 목표와 범위

안드로이드에서 대전 중 빠르게 포켓몬 챔피언스 통계를 확인하는 개인용/비수익 앱. PC 브라우저도 지원한다. 이번 구현은 통계에 집중한다: 포켓몬 랭킹, 한국어 검색, 시즌과 싱글/더블 전환, 포켓몬 상세의 기술/도구/같은 팀/능력 보정/능력 포인트/특성. 트레이너 랭킹은 제외한다.

## 구조

HTML/CSS/JavaScript ES modules로 된 설치 가능한 정적 웹앱(PWA). 프레임워크 및 사용자 서버 없이 공급자의 공개 API를 브라우저에서 직접 조회한다. Node.js 기본 모듈만으로 개발 서버, 배포용 폴더 생성, 단위 테스트를 실행한다. 한국어 이름 사전은 공개 PokéAPI 명칭 자료에서 생성하며 API 식별자/폼을 유지한다. 불명확한 이름은 영문 원문을 보존한다. 의존성 없는 구조는 이 조회 중심 첫 버전에 적합하며 추후 계산/샘플 저장 기능은 별도 모듈로 추가할 수 있다.

## 통계와 정확성

- 공급원: https://championsbattledata.com/api_guide 및 /api-rules/.
- API 자료 날짜/생성 시각과 기기에서 가져온 시각을 분리. API 날짜의 시간대를 임의로 추정하지 않는다.
- 실시간 일치는 불필요하다는 사용자 결정. 전체 통계의 정확성 검증 완료라고 주장하지 않는다.
- 인덱스에 포함된 해당 시즌/날짜/형식의 순위를 사용한다. 다른 시즌/형식의 자료로 조용히 대체하지 않는다.
- 상세 자료는 동일 시즌에서 가장 최근 제공되는 날짜를 선택한다. 순위 시점과 다를 경우 드러낸다.
- null/빈 비율은 없는 값으로 보존한다. 실제 0%와 구분한다. 같은 팀은 순위만 표시한다.
- 능력 포인트는 HP/공격/방어/특수공격/특수방어/스피드 순서. 성격/능력 보정과 결합된 완성 샘플이라고 주장하지 않는다.
- 시즌 전환/빠른 포켓몬 선택 중 이전 요청 응답이 현재 화면을 덮어쓰지 않는다.
- 출처와 비공식 서비스임을 표시. 임시 캐시만 허용하며 영구 미러/통계 일괄 내보내기는 구현하지 않는다.

## 저장과 갱신

기기에 최근 조회 자료만 제한적으로 임시 보관한다. 만료 시 갱신, 실패 시 보관 기간 안의 캐시와 날짜를 명시해서 제공한다. 오래된 캐시는 정리한다. 즐겨찾기와 마지막 형식/시즌은 기기 로컬에 저장한다. 새로고침은 공급원의 새 자료를 조회하며 인게임 갱신을 강제하지 않는다. 정적 앱 파일만 서비스 워커에 저장한다.

## 화면

차분한 밝은 배경, 짙은 네이비 텍스트, 청록색 강조. 상단 브랜드/새로고침, 시즌과 싱글/더블 선택, 자료 시점, 검색과 즐겨찾기, 순위 목록. 모바일 상세는 별도 화면으로 열고 뒤로가기로 목록 위치/검색 유지. PC는 목록과 상세를 나란히 표시한다. 탭은 터치하기 충분한 크기로 배치하고 능력 포인트는 6개 수치를 동시에 읽을 수 있게 구성한다. 로딩/오류/자료 없음/오프라인 상태를 구분한다.

## 검증된 표본

사용자 캡처: 2026-09-19 01시경 KST, 시즌 M-6 싱글 보만다/더블 고릴타. API 2026-09-18 자료와 보만다 도구 상위 5, 능력 포인트 상위 5, 특성 2 및 고릴타 도구 상위 5 일치. 몇몇 비율은 0.1%p 차이. 보만다 같은 팀 5/6위 갑주무사/킬가르도 순서가 반대. 사용자가 실제 6위 킬가르도를 확인했으며 시점 차이를 허용하고 API 기준 시각 표시를 요청했다. 이 표본은 전체 데이터/폼/기간 검증을 대신하지 않는다.

## 이후 범위 (이번 구현 제외)

대전용 싱글/더블 계산기: 내 파티 사전 선택, 상대 대표 설정 2~3개와 추가 투자/보정 0 기본값을 동시 비교, 저장한 상대 샘플 선택 옵션. 샘플/파티 기기 저장 및 파일 백업/엑셀 내보내기. 사용자 간 온라인 공유, 완성형 도감, 파티 상성은 후속 범위.

## 검증 기준

실제 API 응답 조회, 시즌/형식 고립과 순위 및 비율 처리 테스트, 캐시 만료/오류 처리 테스트. 모바일 폭에서 검색/탭/다른 포켓몬 이동/뒤로가기/새로고침, PC 레이아웃, 오프라인 복귀 확인. HTTPS 배포 또는 localhost에서만 설치/서비스 워커가 가능하며 일반 LAN HTTP는 조회 테스트용으로 설명한다.
