# 중단 작업 재개 및 상세 창·이동·이미지 수정 (2026-09-20)

이전 작업은 마지막 모바일 간격 수정 후 빌드/재검증 단계에서 사용 한도로 중단됐다. 재개 후 빌드했고, 추가 요청을 반영했다. 종료되어 있던 로컬 미리보기 서버도 4173 포트에서 다시 실행했다.

## 이동

기존 `랭킹으로`는 `history.back()`을 사용해 같은 팀 링크로 여러 포켓몬을 탐색하면 이전 포켓몬으로 이동했다. 이제 랭킹 경로를 명시적으로 push하고 목록의 기존 검색·필터·스크롤을 유지한다. 별도 `이전` 버튼은 앱 내 이전 포켓몬 기록이 있을 때 표시하고 브라우저 history를 사용한다. 직접 상세 링크로 진입하면 불필요한 이전 버튼은 표시하지 않는다. 상단 로고는 랭킹 맨 위로 이동한다.

## 상세 창

영어·일본어는 한국어 이름 바로 아래에 배치하고 정보 본문과 간격을 둔다. 기술 성질 밑에 구분선을 추가했다. 도구 이미지는 한국어 이름 위에 배치한다. aria-labelledby 연결은 유지하고 누락된 설명/이미지 대체 표시도 유지한다.

## 이미지 조사 및 반영

- [PokéAPI Champions](https://github.com/PokeAPI/sprites/tree/master/sprites/pokemon/versions/generation-ix/champions): 현재 공개 통계 인덱스의 종에 연결된 메가 80종 모두 대응 이미지 존재.
- [PokéAPI HOME](https://github.com/PokeAPI/sprites/tree/master/sprites/pokemon/other/home): 도감에 수록된 나머지 메가 11종의 대체 3D 렌더. 91종 전체에 명시적 경로 연결.
- [PokéAPI gen9 도구](https://github.com/PokeAPI/sprites/tree/master/sprites/items/gen9): 56개 경로. 망나뇽나이트·라이츄나이트X/Y 등 기존 루트 폴더에 없는 파일을 연결한다.

종/폼 식별자는 PokeAPI pokemon.csv와 Showdown ID를 정규화해 대응한다. X/Y/Z는 별도 키로 유지한다. 업데이트 스크립트 `scripts/update-artwork.mjs`는 원격 파일 목록을 확인해 `src/artwork-data.js` 경로 사전을 생성한다. 이미지 자체를 다운로드해 앱에 저장하지 않으며 서비스 워커에도 캐시하지 않는다. PokéAPI는 제3자 이미지 저장소이며 공식 배포 API가 아니다. HOME 대체 이미지까지 최신 모델로 동일하다고 보장하지 않는다. 확인한 버전 폴더의 렌더를 사용한다.

## 검증

- 랭킹 복귀 오류를 재현하는 브라우저 검사가 기존 구현에서 실패하는 것을 확인 후 수정.
- 랭킹→보만다→망나뇽→리자몽→랭킹, 별도 이전/브라우저 앞으로, 직접 상세 링크, 로고 홈 이동 검사.
- 상세 창 이름 간격, 도구 이미지 위치, 기술 성질 구분선, 이미지 실패 시 대체 표시 검사.
- 48개 단위 테스트 통과. 실제 통계 UI 및 오프라인 회귀, 통계 갱신 실패/복구 브라우저 검사 통과.
