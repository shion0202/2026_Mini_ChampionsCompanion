## 샘플과 파티 로컬 저장 검증 — 2026-09-22

`scripts/verify-builds-browser.mjs`를 작성했다. 빈 목록 안내, 저장한 샘플과 파티의 새로고침 후 유지,
이름 검색, 파티의 채운 자리 수, 탭 전환과 뒤로 가기, JSON 내보내기 파일 이름,
가져오기가 기존 항목을 지우지 않고 합치는 것, 형식이 아닌 파일의 안내와 목록 보존,
390px과 1280px 가로 넘침 없음, 다크 테마를 다룬다. 이 화면은 통계 API를 쓰지 않으므로
외부 연결을 모두 차단한 상태로 검증하도록 짰다.

**이 스크립트는 아직 실행하지 않았다.** 이 작업을 한 환경에는 Playwright가 없어서(런타임
의존성으로 추가하지 않고 `PLAYWRIGHT_MODULE`/`BROWSER_EXECUTABLE` 환경변수로 받는 구조라
설치 없이는 실행 자체가 불가능했다) `node --check`로 문법만 확인했다. 실행하려면:

```bash
node scripts/serve.mjs --port 4173
PLAYWRIGHT_MODULE=<playwright 모듈 경로> BROWSER_EXECUTABLE=<브라우저 실행 파일> \
  node scripts/verify-builds-browser.mjs
```

스크립트가 다루는 동작(한국어 이름의 목록 표시, 탭 전환과 뒤로 가기, 이름과 초성 검색,
가져오기가 기존 항목을 덮어쓰지 않는 것, 형식이 아닌 파일의 오류 경로, 기존 다섯 화면,
다크 테마, 375px 폭)은 이 작업을 지시한 사람이 실제 브라우저에서 손으로 확인했다. 이 수동
확인과 위 스크립트의 미실행 상태는 서로 다른 사실이며, 수동 확인이 스크립트 실행을
대신하지 않는다.

### 편집 화면 추가 — 2026-09-23

`scripts/verify-builds-browser.mjs`에 편집 화면 시나리오를 더했다: 빈 값에서 샘플을 새로
만들어 저장하는 것, 저장한 값이 새로고침 후에도 남는 것, 이름을 비우면 저장을 막고 이유를
보여주는 것, 나갔다 돌아온 초안이 이어지는 것. **이 스크립트는 여전히 실행하지 않았다.** 위
문단과 같은 이유로 이 작업을 한 환경에는 Playwright가 없다.

이 수동 확인과는 별개로, 편집 흐름은 이 작업을 지시한 사람이 실제 브라우저에서 손으로
확인했다: 새로 만들고 저장하고 새로고침해도 남는 것, 이름을 비우면 두 가지 이유를 함께
보여주며 편집기가 닫히지 않는 것, 저장이 실패하면 저장소를 건드리지 않고 메시지만 남는
것, 저장에 성공하면 초안이 지워지는 것, 삭제 경고가 몇 개의 파티가 자리를 잃는지 이름으로
알리는 것, 취소를 누르면 아무 일도 일어나지 않는 것, 삭제하면 파티는 남고 그 자리만 비는
것. 이 수동 확인도 스크립트 실행을 대신하지 않는다.
