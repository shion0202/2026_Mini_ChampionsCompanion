# 통계 화면의 배틀 도감 확장

사용자 요청 2026-09-19: 계산기는 후순위. 통계 상세 안에 도감, 효과 설명, 배우는 기술을 통합한다.

## 설계

- 헤더에 시스템/라이트/다크 선택. 기기 설정을 기본으로 하고 수동 선택 저장.
- 랭킹에 사용 순위/한국어 이름/전국 도감번호와 역순, 세대/타입 필터. 현재 통계 목록만 대상으로 하고 복수 조건은 AND. 세대는 종 자체의 첫 등장 세대(지역 폼은 원종 기준)로 명시.
- 포켓몬 상세에 기존 통계와 함께 기본 정보/배우는 기술 버튼. 기본 정보에서 보통/메가 폼을 전환하고 타입, 키·몸무게, 특성, 종족값/실수치, 타입 방어상성을 표시. 통계는 선택한 원래 포켓몬 집계로 유지하며 메가 폼별 통계라고 표시하지 않는다.
- 실수치는 챔피언스 Lv.50 기준 HP=종족값+포인트+75, 나머지=내림((종족값+포인트+20)×보정). 최대(+32,상승)/+32(무보정)/+0(무보정)/최소(+0,하락)를 비교. 특성·도구·랭크 변화는 적용하지 않는다.
- 방어상성은 타입만 계산하며 특성/도구 미적용 문구를 명시. 무효/반감/약점과 접을 수 있는 보통 상성.
- 기술/도구/특성 이름을 누르면 같은 팝업에서 한국어 효과와 기술 기본 수치 확인. 미제공 설명은 임의 생성하지 않는다.
- 배우는 기술은 Showdown champions 전용 목록을 사용. 해당 폼 자료가 없으면 일반 세대 기술로 대체하지 않고 미제공 상태. 검색/타입/물리·특수·변화 필터.
- 능력 포인트는 원본/묶음 토글. 32포인트 능력치 집합이 같은 행만 합산; 32가 없는 배분은 각각 유지. 원본 행을 펼쳐 확인하고 공개된 상위 배분만의 합계임을 표시. 알 수 없는 %는 합계를 알 수 없는 것으로 보존. 사용자가 기준 승인함.

## 구현 순서와 검증

- [x] scripts/update-reference.mjs: 버전 고정 데이터 생성. 종족값/메가/한국어 효과/배우는 기술과 출처를 public/data/reference.json에 저장. 런타임 외부 의존성 추가 없음.
- [x] src/reference.js, tests/reference.test.mjs: 사용자 예시 실수치, 복합 타입, 포인트 합산, 정렬/필터 의미를 먼저 테스트하고 구현.
- [x] src/reference-view.js: 통계에 통합하는 도감/기술/팝업 렌더링을 별도 모듈로 구현.
- [x] src/app.js, index.html, styles.css: 테마, 정렬/필터, 새 상세 항목, 효과 팝업/묶음 연결.
- [x] sw.js: 신규 정적 데이터와 모듈 캐시 갱신.
- [x] 실제 브라우저에서 모바일/PC, 양 테마, 메가 변경, 효과 팝업, 기술 검색, 합산 원본 보존 검증. 기존 통계/오프라인 회귀 검증.

기존 통계 API의 메타데이터는 예시 수치의 의미가 불분명해 종족값으로 사용하지 않는다. Showdown 고정 버전 종족값과 챔피언스 데이터, Project Pokémon champout 한국어 텍스트를 연결하고 출처/미제공을 분리한다. 오래된 시즌 통계에도 도감은 최신 고정 버전이라는 점을 표시한다.
