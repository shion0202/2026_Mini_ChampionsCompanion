# 상세 정보와 다국어 보강 (2026-09-20)

사용자 요청을 반영한 변경:

- 최신 시즌은 `[최신] M-6 (M-C)`, 도감 정렬은 `도감 번호순`, 번호는 `No.003` 형태.
- 한국어 폼 설명은 괄호, 복합 설명만 가운데점 사용. 메가 접두어 유지.
- 필터 도움말, 실수치 안내, 같은 팀 설명을 요청한 문구로 수정. 배분 합산 안내는 목록 아래로 이동.
- 클릭 가능한 이름은 아이콘 대신 점선 밑줄, hover/focus 배경과 눌림 효과 사용.
- 이름/타입과 신체 정보 사이 구분선 추가. 상성 카드는 내용 높이를 유지하도록 위쪽 정렬.
- 10% 이상 비율은 녹색 게이지와 구별되는 황색 배지. 상위 항목 개수에 개/마리 표기.
- 포켓몬 일본어 이름, 기술·특성·도구의 영어/일본어 보조 이름 표시.
- 기술 성질은 상세 팝업에서만 표시. 배우는 기술의 팝업 필터에 기술 성질 추가. 다른 필터와 AND 조건, 취소 시 변경 미적용.

## 데이터

일본어 종 명칭은 PokeAPI CSV 언어 11(없는 경우 1). 폼 설명은 명시적 대응표이며 메가/로토무의 접두어를 보존한다. 현재 통계 인덱스의 모든 종과 수록 메가 폼에 한국어/일본어 명칭이 연결되는 것을 확인했다.

기술·특성·도구의 일본어 명칭은 기존 champout 고정 리비전의 `rom-txt/jpn`을 usa/kor와 같은 키로 연결한다. 기술 성질은 기존 Showdown 리비전 + Champions overrides에서 contact, slicing, bullet, punch, bite, pulse, sound, powder, wind, dance와 recoil/drain/multihit를 추출한다. 반동은 recoil 필드를 기준으로 하며, 자폭/실패 시 피해 등 모든 자해 효과를 임의로 반동으로 취급하지 않는다. 기술 타입과 기술 성질은 별개 필터다.

## 능력 포인트 20위 제한

렌더러는 원본 순위 20위까지 표시 및 합산한다. 하지만 2026-09-19 M6 공개 일별 파일은 싱글·더블 모든 포켓몬에 능력 포인트 10행만 제공했다. 별도의 `/api/battle/Singles/salamence?season=M6&days=1`에서도 같은 날짜 10행뿐이었다. 따라서 현재 실제 화면에는 제공된 10개가 표시되며 11~20위는 추가되지 않는다. 다른 날짜를 합치거나 없는 행을 만들지 않는다. UI를 위해 별도 API 요청을 늘리지 않았다. 제공 범위가 늘면 20위까지 자동 표시된다.

사용률 변화 그래프는 요청에 따라 후순위로 보류했다.
